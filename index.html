Política de Privacidad — BONOXS

Última actualización: 6 de agosto de 2026

Esta Política de Privacidad describe cómo BONOXS ("el bot", "nosotros") recolecta, usa y protege los datos de los usuarios de los servidores de Discord donde está presente.

1. ¿Qué es BONOXS?

BONOXS es una aplicación de Discord personalizada (Custom Bot) que utiliza la infraestructura de MEE6 (mee6.xyz) a través de su servicio "Bot Personalizer / Custom Bot". Esto significa que, si bien BONOXS opera bajo su propia identidad (nombre, avatar, aplicación registrada en Discord), el procesamiento técnico de datos (mensajes, miembros, niveles, roles) es realizado por los servidores y sistemas de MEE6 en nuestro nombre.

2. Datos que recolectamos

A través de las funciones activas del bot (Sistema de Niveles/XP, Reaction Roles y Sorteos), se procesan los siguientes datos:

  • Identificadores de Discord: ID de usuario, nombre de usuario, avatar, ID del servidor (guild).
  • Datos de actividad de mensajes: se detecta el envío de mensajes para calcular experiencia (XP) y nivel. El contenido textual de los mensajes no se almacena de forma permanente; solo se utiliza de forma transitoria para el conteo de actividad.
  • Datos de niveles/XP: puntaje de experiencia y nivel asociado a cada usuario, usado para tablas de clasificación (leaderboard).
  • Reacciones a mensajes: qué emoji reaccionó un usuario en mensajes configurados para asignación automática de roles (Reaction Roles).
  • Participación en sorteos: ID de usuario de quienes reaccionan/participan en un sorteo, para poder seleccionar ganadores.
  • Lista de miembros del servidor: necesaria para verificar membresía activa al momento de asignar roles o seleccionar ganadores de sorteos.

3. Cómo se procesan y almacenan los datos

Los datos mencionados son procesados y almacenados por la infraestructura de MEE6, proveedor tecnológico de BONOXS. MEE6 mantiene su propia Política de Privacidad, disponible en: https://mee6.xyz/en/privacy.

Los datos se conservan mientras el bot permanezca activo en el servidor. Si el bot es expulsado de un servidor, los datos asociados a ese servidor dejan de utilizarse.

4. Uso de los datos

Los datos recolectados se usan exclusivamente para:

  • Calcular y mostrar niveles/XP de los miembros.
  • Asignar o remover roles automáticamente según reacciones (Reaction Roles).
  • Gestionar sorteos: registrar participantes y seleccionar ganadores.

No utilizamos estos datos con fines publicitarios, no los vendemos ni los compartimos con terceros ajenos a la infraestructura necesaria para operar el bot (MEE6).

5. Entrenamiento de modelos de IA

Los datos de contenido de mensajes no se utilizan para entrenar modelos de aprendizaje automático o inteligencia artificial.

6. Derechos del usuario

Cualquier usuario puede solicitar acceso, corrección o eliminación de sus datos asociados al bot contactándonos a través de: contacto@cfaprod.com.

Un usuario también puede optar por no participar dejando el servidor de Discord donde el bot está activo, lo que detiene la recolección de nuevos datos sobre esa persona.
