Política de Privacidad — BONOXS Compras

Última actualización: 6 de agosto de 2026

Esta Política de Privacidad describe cómo BONOXS Compras ("el bot", "nosotros") recolecta, usa y protege los datos de los usuarios de los servidores de Discord donde está presente.

1. ¿Qué es BONOXS Compras?

BONOXS Compras es una aplicación de Discord desarrollada y operada directamente por nosotros (no utiliza infraestructura de terceros como MEE6). Su función es verificar comprobantes de compra enviados por los usuarios y otorgar roles de reconocimiento tras la aprobación de un miembro del staff.

2. Datos que recolectamos

  • ID de usuario de Discord: para identificar de forma única a cada usuario que envía una solicitud.
  • Estado de la solicitud: aprobado o rechazado.
  • Rol asignado: el rol otorgado tras la aprobación.

Las imágenes de comprobantes de compra que los usuarios envían no se descargan ni se almacenan en nuestros servidores; permanecen alojadas en la infraestructura de Discord (CDN) y solo son visualizadas por el staff dentro del canal correspondiente para su revisión.

3. Cómo se procesan y almacenan los datos

Los datos mencionados se almacenan en una base de datos SQLite propia, alojada en un servidor privado (VPS). La base de datos está cifrada en reposo mediante SQLCipher (AES-256).

Los datos se conservan mientras el usuario mantenga el rol otorgado, con el fin de evitar aprobaciones duplicadas.

4. Uso de los datos

Los datos recolectados se usan exclusivamente para verificar solicitudes de compra y gestionar la asignación de roles asociados. No utilizamos estos datos con fines publicitarios, no los vendemos ni los compartimos con terceros.

5. Entrenamiento de modelos de IA

Los datos recolectados no se utilizan para entrenar modelos de aprendizaje automático o inteligencia artificial.

6. Derechos del usuario

Cualquier usuario puede solicitar acceso, corrección o eliminación de sus datos asociados al bot contactándonos a través de: contacto@cfaprod.com.

Un usuario también puede optar por no participar simplemente no enviando comprobantes de compra al bot, o dejando el servidor de Discord donde el bot está activo.

7. Contacto

Para consultas sobre esta Política de Privacidad: contacto@cfaprod.com
